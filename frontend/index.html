Security Architecture, Custody Model & Privacy Policy

Non-Custodial Smart Accounts

Sivan Ai never holds custody of private keys or pool funds. Users authenticate through non-custodial smart accounts or deterministic Web3 key pairs on Celo (Chain ID 42220). Service agreements lock funds in autonomous on-chain smart contracts with strict multi-sig or timelock release conditions.

Cryptographic Verification & Speed

Internal ledger and smart account balance state transitions execute in 0.15 seconds (sub-second). External fiat conversions route via licensed liquidity providers into Nigeria's NIBSS NIP network with standard completion under 1 to 2 minutes.

Privacy & Data Protection

User personal financial data is never sold or broadcast. Local storage is strictly limited to user theme preferences and client-side session tokens. All on-chain transactions are publicly verifiable via Celo Mainnet explorers using deterministic contract addresses.

Transparent Fee Architecture Separation

Sivan Ai strictly separates protocol transfer fees from external fiat off-ramp fees.
